# My Portfolio

I am Anaya Martin, a Moringa School student studying programming, and this is my portfolio, which introduces me, lists my skills, and showcases the projects I've built.

### Sections

- **Header:** my name, a tagline, and a link to my GitHub profile
- **About Me:** a short bio and a skills list
- **Projects:** a responsive card grid with a description and GitHub link for each project
- **Footer:** copyright line

### Projects featured

HustleNShine - Website for a mobile car detailing service, with services and appointment booking 
HS - Redesigned HustleNShine site with a modern UI, blog section, and contact form 
My Portfolio - This website 

## Design

- Dark theme with a plum and magenta palette
- Headings in [Fraunces] and body text in [Work Sans], loaded from Google Fonts
- Centered header and a max content width of 1000px
- Projects laid out with CSS Grid, so cards reflow from three columns down to one on small screens
- Skills displayed as pill-shaped tags with Flexbox
- Visible keyboard focus style on links
